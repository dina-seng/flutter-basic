# Clinic Appointments Practice

This project reproduces my Week 4 Clinic Appointments test submission **exactly as submitted**, including all bugs and incomplete implementations.

> **Note:** This project intentionally contains flawed and broken code for personal debugging practice. Do not use it as a reference implementation.

---

## Setup

Install dependencies:

```bash
dart pub get
```

## Running the Tests

```bash
dart test lib/test/appointment_test.dart
```

Or simply:

```bash
dart test
```

---

## Important Notice

The source code in this project **faithfully reproduces a flawed exam submission** (scored 10/100). The cancellation feature and its associated tests are intentionally incorrect. Compilation errors and test failures are expected — they are the bugs to be fixed as a learning exercise.
